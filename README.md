# AdventureWorks2022-SQL-Analysis
## Project Summary
A practical SQL Server project using the AdventureWorks2022 database to explore business data and answer real world analytical questions.

## What Was Done
- Created **40 independent SQL queries** addressing business questions related to sales, customers, products, and business performance.
- Organized the queries into **5 sections**, progressing from basic data exploration to advanced analysis.
- Worked with multiple related tables using different types of JOINs.
- Calculated business metrics using aggregate functions, GROUP BY, HAVING, and CASE statements.
- Applied CTEs, subqueries, and window functions to perform deeper analysis.
- Explored sales trends, customer activity, product performance, rankings, and running totals.

## Technologies
Microsoft SQL Server | T-SQL | SQL Server Management Studio (SSMS)
